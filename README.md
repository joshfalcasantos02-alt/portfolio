# Joshua M. Falcasantos — Portfolio

Personal portfolio of Joshua M. Falcasantos, full-stack developer and BS Information Technology student at Western Mindanao State University.

**Live site:** https://joshfalcasantos02-alt.github.io/portfolio/

## Contents

- `index.html` — the portfolio page
- `support.js`, `vendor/react*.js` — the runtime that renders the page

## Running locally

Serve the folder (e.g. `python -m http.server`) and open `index.html`;
some browsers block the scripts over file://.
